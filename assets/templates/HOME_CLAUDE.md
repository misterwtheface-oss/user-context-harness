# Rules inside this workspace

This folder is the home for all Claude work. `README.md` is the map; read it when unsure where something goes.

- Work on one project at a time. Its folder is under `projects/`; open `CONTEXT.md` then `PROGRESS.md` first.
- New files go in the active project's `files/` folder. Unsorted things go in `inbox/`.
- Keep `PROGRESS.md` honest at the end of every session. If it grows past a screen or two, move old items to the
  project's `archive/` folder as a dated file rather than deleting them.
- Moves of existing files happen only after a listed yes, and every move is appended to `inbox/MOVED.md`.
- Finished projects move whole into the top-level `archive/`.
- Write for the person who owns this folder: plain words, click paths alongside full paths.
